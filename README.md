## 项目内容

- React / Vinext 前台与管理界面。
- 匿名文字咨询、固定首次自动回复、管理员回复。
- 单管理员登录、首次改密、服务端权限检查。
- 图片与视频动态，支持16:9与9:16。
- D1数据库结构与迁移，R2媒体存储接口。
- 手机、平板、电脑响应式布局。
- 你提供的首页视频及封面。
